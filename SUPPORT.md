# Getting help

Where to go depends on what you need.

| You need | Go to |
| --- | --- |
| To report a bug in Ekklesia | A [bug report](https://github.com/crismag/Ekklesia/issues/new/choose), with fictional or redacted data |
| To propose a feature or describe a church workflow | A [feature proposal](https://github.com/crismag/Ekklesia/issues/new/choose) |
| To install or run your own copy | The [installation guide](docs/deploy/installation.md) and [documentation index](docs/README.md) |
| To report a security problem | Privately, as described in [SECURITY.md](SECURITY.md); never in a public issue |
| Help with a problem specific to your installation | Your own administrator first; then a public issue if it looks like a bug, with private details removed |
| Paid deployment, configuration, data import or customization | [CrisHub](https://crishub.com/contact/) |

If you use Christlikeness Church's portal as a member, ask the church's
administrators; this repository is for the software, not for church accounts.

## What to expect

Ekklesia is free software maintained by one person. Public issues are read and
answered when time allows; there is no guaranteed response time, and the
source code being available does not include free installation support or
ongoing maintenance of your installation. Paid assistance is available
separately through CrisHub, by agreement.

## Before you post

Remove names, email addresses, phone numbers, birthdays, addresses, passwords,
tokens and `.env` contents from anything you share, including screenshots and
logs.
